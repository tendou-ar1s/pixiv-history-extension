# Pixiv 浏览记录（Chrome / Edge 扩展）

在 pixiv 网页版自动记录你看过的作品，随时在页面右侧的浮动面板回看。
无需登录任何第三方服务，数据只存在你自己的浏览器里。

## 功能

- 打开作品详情页时自动记录：封面缩略图、标题、作者、浏览时间
- 同一作品重复访问 → 更新时间并置顶
- 最多保留 1000 条，超出自动淘汰最旧
- 侧边面板：关键字搜索（标题/作者）、单条删除、一键清空历史
- 快捷键 `Shift+H` 开/关面板
- 多标签页同步：任一 pixiv 标签页的新记录即时出现在面板顶部

## 安装

1. 下载本目录
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）
3. 右上角打开「开发者模式」
4. 点「加载已解压的扩展程序」，选择本目录

## 使用

| 操作 | 方式 |
|---|---|
| 开/关面板 | `Shift+H` |
| 搜索 | 顶部搜索框输入标题/作者关键字 |
| 打开某条记录 | 点击该条（新标签页打开） |
| 删除单条 | 悬停该条，点右上角 ✕ |
| 清空历史 | 底部「清空历史」按钮 |

## 隐私

- 仅申请 `storage` 权限，数据 100% 存于本机 `chrome.storage.local`
- 不采集、不上传任何数据；不请求任何第三方服务
- 封面复用页面已加载的 CDN 缩略图；仅当页面 DOM 无法取得封面时，
  向 pixiv 官方页面同源接口（`/ajax/illust/{id}`，附带你的登录态）请求一次作品信息用于封面

## 目录结构

- `manifest.json` — MV3 配置（仅 storage 权限，仅作用于 www.pixiv.net）
- `content/core.js` — 纯函数模块：路由匹配 / DOM 元数据提取 / 去重置顶 / 相对时间 / 串行写队列
- `content/recorder.js` — SPA 路由劫持与记录落盘
- `content/panel.js` — Shadow DOM 面板 UI
- `content/panel.css` — 面板宿主元素定位
- `test/` — 浏览器内单元测试（打开 `test/page.html` 即可运行，无需构建工具）

## 已知边界

- pixiv 改版导致选择器失效时，记录会退化为「链接 + 时间」（面板显示
  「未获取到标题」），不会崩溃
- 未登录 / R18 拦截页无元数据时，对应字段存为空
